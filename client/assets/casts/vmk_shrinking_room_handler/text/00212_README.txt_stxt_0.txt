The view string will then be rendered, there should be different renderer classes thatare abstracted from the actual scroller as separated classes. The renderers can render the text asnormal text or in any format necessary. Possible rendererClasses might be: text, bitmap, isometricLeft, isometricRising, isometric, vertical, horizontal etc....The special characters:The special characters will intervene the normal animation and do special functions such as pause for an amount of seconds, stop and blink the text for a while, show a special error message, scramble the view for a while....The special characters for selected actions are configured as such:| = pause for 3 seconds$ = pause to blink for 3 seconds@ = scramble the display for 3 seconds (show random characters for 3 seconds....)The scroller itself should only know the following at any one time: - the source-text- the amount of characters in the viewable area- the currently viewed text- the speed it should advance with- the index in the source-text, the scrollerRenderer.-- if no renderer is active then the viewable text will be put into the default output.
